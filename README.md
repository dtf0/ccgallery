ccgallery
=========

*Coder Cowboy Gallery* - A simple web gallery generator. Generates static html/js/css that does not require your web host to run any other software. See a demo of ccgallery in action [here](https://onejasonforsale.com/gallery/).

<img style='width:300px' src="ccgallery-demo-small.gif"></img>

Setup
=====

1. Install [nodejs](https://nodejs.org/en) and [npm](https://www.npmjs.com/) with your package manager (such as [Homebrew](https://brew.sh/) for MacOS)
2. Run `npm install` in the root folder of this project
3. More here later!!
